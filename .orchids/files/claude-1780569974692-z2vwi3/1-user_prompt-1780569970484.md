Events Page (/events)
Layout
Centered content column capped at max-w-7xl with px-6 padding. Content starts 64px below the navbar (pt-16). Bottom padding 96px. Three main stacked zones: header + search, filter chips, event grid.

Zone 1 — Page Header & Search
Heading: "Discover Events" in Playfair Display 5xl, medium weight, navy. Below it a subtitle in Inter 18px, light weight, muted grey: "Join curated gatherings in your city and practice languages in a natural, immersive environment."

Search bar: Below the subtitle, max-width max-w-2xl. A rounded-full input (py-4 pl-12 pr-6) on a white card background with a faint border. A Search icon (lucide) sits absolutely positioned inside the left edge (left-4), muted grey. On focus: 2px ring in gold at 50% opacity, border turns gold. Placeholder text: "Search for events, languages, or cities..." Search is live — the value is wired to a state variable that filters the API query on change.

Zone 2 — Filter Chips
A horizontal wrapping row of 4 pill buttons: City · Category · Language · Date

Each button: bg-card border border-border px-5 py-2.5 rounded-full text-sm font-medium shadow-sm. On hover: border turns gold at 50% opacity, background shifts to the warm beige accent. A ChevronDown icon (16px, muted grey) sits to the right of the label inside each pill. Currently decorative (no dropdown logic).

This row fades in 100ms after the header with the standard fade-in animation starting from opacity-0.

Zone 3 — Event Grid
A responsive 3-column grid (grid md:grid-cols-2 lg:grid-cols-3 gap-8).

Loading state: 3 skeleton cards, each with a grey shimmer block for the image area and shimmer lines for the text.

Empty state: A full-width col-span-full centred muted grey message: "No events found matching your search."

Event Card (repeated per event):

Each card is a white rounded-3xl with border border-border/50 shadow-sm. On hover: shadow lifts, card rises 4px (hover:-translate-y-1), transition 500ms. The card is a vertical flex column so the button always sits at the bottom. Cards fade in sequentially — each card's animation delay is 0.2s + (index × 0.1s).

Card top — image area (h-48, full width):

A CSS gradient fill that cycles through 3 variants based on card index:
Index % 3 === 0: from-primary/20 to-primary/40 (faint gold)
Index % 3 === 1: from-slate-200 to-slate-300 (cool grey)
Index % 3 === 2: from-amber-200 to-amber-400 (warm amber)
Top-left: category badge — text-xs font-semibold px-3 py-1 rounded-full bg-white/50 backdrop-blur-md text-foreground
Top-right: a save/heart icon button — w-8 h-8 rounded-full bg-white/20 backdrop-blur-md, hover lightens to bg-white/40. Contains an SVG heart path (stroke, not fill).
Card body (p-6 flex-1 flex flex-col):

Event title in Playfair Display 2xl, medium, leading-tight, navy
Organizer: "by [organizerName]" in Inter 14px, muted grey — mb-4
Three metadata rows (space-y-2 mb-6), each is a flex row with a w-4 h-4 text-primary icon + 14px text:
Calendar icon + formatted date ("Oct 24 • 19:00" style)
MapPin icon + city name
Users icon + "X / Y participants" count
Description text: 14px, muted grey, line-clamp-3, flex-1 to push the button down — mb-8
"View Details" button (full width): links to /events/:id — gold background, white text, rounded-xl py-3.5 text-sm font-medium, shadow lifts on hover. mt-auto anchors it to the bottom.
Create Event Page (/events/create)
Layout
Centered narrow column, max-w-3xl px-6 pt-16 pb-24. Two stacked elements: a centered text header, then a single large white form card.

Page Header (centered)
Title: "Create New Event" in Playfair Display 4xl–5xl (responsive), medium, tight tracking — mb-3. Fades in at 0.4s.
Subtitle: "Bring people together and share your passion for language." Inter 18px, light weight, muted grey.
Form Card
A white rounded-3xl p-8 md:p-12 shadow-sm border border-border/50. Fades in at 0.5s with 100ms delay, starting from opacity-0. All fields use space-y-8 vertical spacing inside the form.

Input field style (shared): Warm beige background (bg-background), faint border, rounded-xl py-3.5 px-4. On focus: background turns white, 2px gold ring at 30% opacity, border turns gold. Placeholder text at 70% muted-foreground opacity.

Field 1 — Event Title (full width):

Label: "Event Title" — Inter 14px medium
Plain text input, placeholder: "e.g. Evening French Conversation in the Park"
Field 2 — Description (full width):

Label: "Description"
<textarea rows={4}>, no resize (resize-none), placeholder: "What will you do? Who is it for? Any level requirements?"
Fields 3–6 sit in a grid md:grid-cols-2 gap-8:

Date & Time — datetime-local input. A Calendar icon (16px, muted grey) is absolutely positioned left (left-4), input has left padding pl-11 to clear it.

City / Location — text input with MapPin icon pinned left, placeholder "e.g. Berlin"

Max Participants — number input, min="2", with Users icon pinned left, placeholder "e.g. 10"

Primary Language — <select> with a Type icon pinned left (pl-11) and a ChevronDown icon pinned right (right-4, pointer-events-none, decorative). appearance-none to hide the native arrow. Options: English, German, Spanish, French, Italian, Portuguese, Japanese, Chinese, Arabic, Other. Default disabled option: "Select a language"

Category — <select> spanning both columns (md:col-span-2), no left icon, ChevronDown pinned right. Options: Language Exchange, Culture, Professional, Social, Sports, Other. Default disabled: "Select a category"

Submit section — separated from the fields by a pt-6 border-t border-border/50:

"Publish Event" button (full width): gold bg, white text, rounded-xl py-4 text-base font-medium. Shadow: shadow-lg shadow-primary/20, lifts to shadow-xl shadow-primary/30 on hover. Rises 2px on hover (hover:-translate-y-0.5). While submitting: label changes to "Publishing...", button is disabled and dimmed (disabled:opacity-50), lift is removed.
On successful submission: a toast notification "Event created successfully" appears, and the user is redirected to the new event's detail page (/events/:id).
On validation failure (any required field empty): a destructive toast "Please fill out all fields" — no network call is made.
On API error: destructive toast "Failed to create event".
